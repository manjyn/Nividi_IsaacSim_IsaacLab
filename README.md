# NVIDIA Isaac Sim · Isaac Lab 학습 자료

NVIDIA Isaac Sim과 Isaac Lab을 활용한 로봇 시뮬레이션 및 개발 학습 자료를 모은 개인 저장소입니다. 한국어 가이드와 참고 문서를 통해 로봇 개발에 필요한 개념을 익히고, 실습 과정에서 필요한 내용을 찾아볼 수 있도록 구성했습니다.

## 주요 자료

- **Isaac 실무 입문 가이드**: 학습을 시작하기 위한 입문 자료
- **Isaac Sim · Isaac Lab 가이드**: 시뮬레이션과 로봇 학습 관련 참고 자료
- **Unity 연계 가이드**: Isaac Sim과 Unity 활용 참고 자료
- **사족보행 로봇 개발 파이프라인**: 개발 흐름을 이해하기 위한 문서
- **로보틱스 용어집 및 ROS 2 Jazzy 교재**: 기초 개념과 관련 기술 학습 자료
